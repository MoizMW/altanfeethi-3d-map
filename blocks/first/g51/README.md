# G51 first-floor window lounge

Open `/?block=first/g51`. H27 and H30 support four tan bucket chairs and two side tables (four seat IDs). H30's background H94/H95 and Table_H36 are G50 objects and are not duplicated here.

All assigned normal and wide captures and all normal-view ROI overlays were reviewed. Normal images are 1920 × 1080; overlays were inspected at 960 × 540. Normal ROI coordinates were never applied to wide images.

Local +X runs from glazing to the open dark-tiled aisle. +Z follows the window row from the wood end toward G51. The glazing has slim mullions and horizontal transoms; gathered sheer curtain pairs leave open views through the glass. A low stone sill supports a dark pierced ornament using the same shared design as G50. Floor dimensions, ceiling height and all placements are provisional meters. Glazing, curtains, pale rugs and visible side fixtures use shared builders; unknown boundaries remain open.

The existing `armchair / egg-swivel` asset approximates the tan leather bucket chairs. G50 owns the adjoining cylindrical display; standalone G51 deliberately omits that neighboring object. See [fixture references](../../../shared/assets/library/references/window-lounge/README.md). Marble veins, changing display content, small window sculptures, exact upholstery and cladding curves remain simplified or unresolved.

Open `/?layout=first/g50-g51` for the connected row. Edit furniture in the source blocks; the combined view loads it live. Saving the editor changes only `objects.json`. No seat/table ID is generated for unannotated background seating. Site measurements and owner review are still needed for dimensions, slot ordering and global alignment.
