# H31 food-buffet assets

Reusable, opt-in geometry in `app/buffet-objects.js`: capsule-shaped stone island with central tree opening and serving pans; rounded hot station with covered trays and heat lamps; horseshoe coffee counter with equipment and cups; illuminated rear display shelves over a slatted cold-service cabinet. Shapes, stone striations, warm emissive plinths, stainless pans and simplified equipment follow H31 normal/wide. The living tree reuses `center-tree-bed`; the service door reuses `timber-office-door`.

The native group is normalized to existing type dimensions so source size/scale/yaw remain editable. Food stocks, lettering and exact appliances are omitted. No new raster texture or camera-photo surface is used. Assets are registered before placement in G56 and library inventory is refreshed.
