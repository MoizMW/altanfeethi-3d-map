# Shared lounge sofa · 4 November 2026

The owner requested the default sofa match the supplied front, side and room views: warm darker off-white/greige woven upholstery, two full back cushions, two plump seat cushions, soft substantial arms and light-blue pillows with dark piping. The differing photographed shades are treated as lighting variation; the common master uses one warm off-white finish.

`app/lounge-sofa.js` builds the shared sofa for the editor and library. It includes cloth weave bump at physical scale, fabric sheen, rounded padded surfaces, cushion seams, connected dark timber feet and two plain light-blue pillows. Pillow fabric is procedural and solid-colored; no photograph or distorted image is applied to it. The existing chair design and generated chair-pillow print remain independent.

All 50 saved sofa placements use the new finish `#aaa59c`. Pillow material is `#708e9b` with dark `#293c47` piping. These material inputs are chosen for the project's shared lighting rather than as calibrated samples of the real fabric.

The master retains the 2.05 × .88 × .9 m reference envelope. Each source object's saved size, scale, position, rotation, object ID and seat IDs are preserved. The gallery's Pillow checkbox hides both decorative pillows together for inspection.

The original owner reference images are saved as `front.png`, `side.png` and `room.png`.
