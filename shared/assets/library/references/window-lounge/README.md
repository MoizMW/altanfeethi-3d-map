# Window lounge fixtures

Window detailing uses three additional shared designs in `app/lobby-fixtures.js`: `wall-panel / window-drapery` provides pairs of gathered, translucent pleated panels with open centers, hems and a top track; `cabinet / window-sill` provides a low stone sill and cap; `display-console / window-sculpture` provides the dark pierced, tapering ornament on a small base seen in H23/H25/H26/H30. Sculpture placements sit on the sill at Y=0.24. Existing full-width opaque `pleated-curtain` objects in other blocks retain their original design. The G50/G51 curtain IDs stay stable while using the new gathered design. Window mullions, transoms, cloth opacity, ornament shape and spacing remain photographic approximations.

Two shared procedural designs in `app/lobby-fixtures.js` support the first-floor G50/G51 window row. Both are registered in `shared/assets/catalog.json` and use the same `buildObject` entry point in the library and rooms.

- `screen / curved-bronze`: shallow curved bronze divider, pale stone cap and dark upright ring ornament. Reference envelope 2.9 × 1.65 × 0.5 m. H56/H25 normal and wide captures show its two sides behind the pale sofas. Exact curvature, finish and dimensions are estimates.
- `wall-panel / cylindrical-display`: full-height circular display column with dark plinth and horizontal panel seams. Reference envelope 1.35 × 4.1 × 1.35 m. H26/H27/H30 normal and wide captures establish the circular wrap and position between the chair groups. The shared `app/cylindrical-display.js` now recreates the palm/oasis campaign with Arabic copy and the red-lit building scene as a 24-second loop with gentle panning and two-second cross-fades. The original video and timing are unavailable, so this is a reference-based reconstruction, not recovered footage.

The built-in image-generation tool created the clean two-frame artwork in `shared/materials/textures/window-display/campaign-atlas.png`; its exact prompt is recorded beside it. The texture contains artwork only; Arabic `خطوة بسيطة` / `لحياة أفضل` and the visible plinth wordmark are rendered in canvas. The portrait creative repeats twice around the column to remain readable from both sides. Screen color is independent of scene lighting. Updates are capped at 15 fps, follow the renderer's lifecycle, respect reduced motion, and dispose their texture with the material. Both the library and room use this same asset; no additional animation loop or timer is created.

Geometry is authored once and normalized to the existing type reference dimensions, so saved size, scale and yaw continue to work. Existing variants retain their builders. G50 owns both sofa dividers and the display column; G51 references the neighboring column instead of duplicating it. Refresh the library inventory after placing the assets.
