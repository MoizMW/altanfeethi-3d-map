# Reception flag artwork

These local SVGs are used as fabric textures in the 3D reception. They load without contacting external sites at runtime.

- `saudi-source.svg`: [Saudi national flag vector](https://commons.wikimedia.org/wiki/File:Flag_of_Saudi_Arabia.svg), downloaded from the Wikimedia Commons original on 2026-11-02. Commons identifies it as public-domain artwork and references the Saudi Flag Website. Shahada and sword paths are retained exactly.
- `saudi.svg`: the source flag turned 90 degrees for a hanging indoor flag, matching the vertical drape seen in ReceptionCam3. The cloth mesh folds the surface; the reverse face uses corrected UVs so the inscription is not mirrored.
- `altanfeethi-logo-source.svg`: official [Altanfeethi logo vector](https://altanfeethi.com.sa/Style%20Library/Portal/images/logo.svg), downloaded on 2026-11-02. The mark and bilingual wordmark remain the property of Altanfeethi; included solely to reconstruct the user's branded reception.
- `altanfeethi.svg`: official vector geometry centered on ivory flag fabric and turned for hanging. White website lettering is recolored dark to match the flag in ReceptionCam3; the official emblem gradient is retained.

Original source vectors are preserved for attribution and review. No external SVG references, scripts, fonts, camera people, photographic shadows or construction objects are included. Only the two finished texture filenames are served by the local editor.
