# Reception logo

`altanfeethi-reception.svg` reuses the official vector geometry and fills from `../flags/altanfeethi-logo-source.svg`, including the white bilingual wordmark and original emblem gradient. Only intrinsic render dimensions were added (1600 × 1158.48); the 400 × 289.62 viewBox and all paths are unchanged. It is mapped onto a transparent plane at the original aspect ratio, separate from the wall material.

The source was downloaded from the official Altanfeethi site on 2026-11-02, as recorded in [the flag asset attribution](../flags/README.md). The artwork remains Altanfeethi property and is used only for the user's reception reconstruction. No external runtime request is required.
